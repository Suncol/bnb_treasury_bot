# 04: 空闲期解除完整收入审计门槛，保留本机结算证明

**Blocked by:** 02：仅按固定库存阈值决定补货紧迫度；03：空闲期接受外部现货余额，操作期间固定严格核对窗口。

**Status:** done

**What to build:** 在没有本机严格核对窗口时，使用有效的当前合约与现货观察完成固定阈值库存决策和下一次操作准备，不再为此证明过去全部合约收入或生成历史保证金指标；操作开始后仍严格核对该窗口所需的结算证据。

**Context:** 当前历史保证金证明、库存状态持久化和执行资格共享完整收入审计前提。本票真正切断这条无关依赖，同时保留 USDⓈ-M 资产级额度、一致性检查和新操作后的严格结算。本票依赖固定阈值完成，避免取消历史指标后仍留下依赖其语义的预测决策。

**Scope:** 从当前账户读取、基线切换、库存周期推进、预算检查到执行前准备形成一条完整路径；诊断性历史与本机结算证据使用不同资格，不增设后台指标服务。

**Acceptance criteria:**

- [x] 空闲阶段，缺少 6h/24h 快照、保证金历史基线、完整旧收入或旧区间资本流水分类，不再阻止库存状态、候选计数、成功库存时间和合规新动作。
- [x] 在无需本机结算或其他明确业务证据的空闲路径中，即使合约收入接口被测试替身设为不可调用，也能完成有效库存周期和下一操作的提交前准备；不得通过输出零指标假装历史证明成功。
- [x] 当前账户模式、币种支持、总额与资产行、钱包/版本以及资产级 maxWithdrawAmount 的现有校验保留；不扩大到多资产模式或新保证金币种。
- [x] 合约与现货接受新基线时记录同一可追踪的证据边界；下一本机操作从最终有效账户开始严格核对，不再回放到已接受外部变化之前的旧历史基线。
- [x] 旧快照和原始回执保留；明确区分库存观察记录、本地回执游标和可用于本机结算的证据。不能把本地游标、请求时间或资产 updateTime 当成已覆盖特定操作的因果证明。
- [x] 在严格窗口内，缺失必须的成交明细、实际费用、划转身份、收入或任一侧余额覆盖，仍保持阻断。补齐后恢复同一操作，不补发、不重置预算与保护累计。
- [x] 对跨基线边界迟到的回执，不能仅按回执时间判定其已经反映在新余额。归属无法证明时保留原始记录并阻断相关严格窗口，不丢弃、重复重放或吸收为外部输入。
- [x] 所有库存推进和直接执行入口使用新的观察/窗口资格；不得通过遗留的收入审计标志重新引入空闲期全面审计，也不能产生只检查余额的直接执行旁路。
- [x] 保留账户级滚动 24h 调出预算：人工及其他策略相关划转、PENDING、未决本机预占、身份去重和超过 24h 仍未决的预占均按原规则计算；回扫不返还预算。
- [x] 预算所需的划转读取仍必需，读取失败不能按零预算使用额放行；maxWithdrawAmount、最小粒度硬 veto、单次比例、划出前后绝对下限及最终复核全部保持。
- [x] 最新观察或预算使候选金额/需求改变时，结束旧候选，不在同轮自动改量重试；后续正常规划仍可生成新候选。行情/过滤器原始有效期、保护动作失效令牌和有界重读保持。
- [x] 按用户在审查修复阶段的新决定：本机调资有可靠身份、已确认结算、相关操作无未决，其他交易条件满足且当前可用资金不足最小合规买单时结束旧续作；只记录当前资金不足，不声明外部支出/冻结归因。
- [x] 复审补充：按实际可挂层位价格、数量步长、最小量/名义金额及费用预留判断最小买单；参考价折算为空但仍可缩量买入时继续旧续作。5.99 USDT、含费临界值等于/略高/略低、层位占用及订单响应丢失后重启均有回归覆盖。
- [x] 二次复审补充：已有有效旧网格订单时，正常分层保留原空层截取与分配；最小订单回退在有剩余槽位时按原顺序检查全部未占价格，最多返回一笔。覆盖 5.92 USDT、最低层含费临界值、槽位耗尽、价格占用及重启恢复。
- [x] 新 baseline 本身不结束续作或追加调资；迟到外部回执不是退出的来源证据。退出与下一有效库存周期屏障原子保存，跨重启/同时间重放/预算自然释放仍保留；后续库存周期通过冷却、预算及全部划转风控才可能补资。
- [x] 新 ADR 明确取代原“任何新库存/执行批次都需完整收入审计”的部分要求，保留严格窗口内的要求与账户新鲜度保障；同步设计和词汇，新增 ADR 0005 明确取代外部占用证明条件，保留同轮禁止补资和下一周期屏障。
- [x] 离线端到端验证空闲外部合约盈亏/入金、缺失旧历史、相关外部活动订单、三种本机划转方向、严格窗口内迟到收入，以及保护动作导致的资格失效。

**Verification:** 使用同一笔外部余额变化，分别放在本机窗口外与窗口内；前者按当前有效库存完成新周期，后者保持严格核对直到证据补齐。对最终额度、预算或订单变化注入竞态，确认无旧候选写出。

**Out of scope:** 接受最终一致余额代替本机结算证明、修改未知划转恢复、仅机器人预算、新买入金额预算、以余额替代本机请求结算。
