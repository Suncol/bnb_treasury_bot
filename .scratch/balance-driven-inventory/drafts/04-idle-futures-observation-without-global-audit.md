# 04: 空闲期解除完整收入审计门槛，保留本机结算证明

**Blocked by:** 02：仅按固定库存阈值决定补货紧迫度；03：空闲期接受外部现货余额，操作期间固定严格核对窗口。

**Status:** draft — 待拆分与发布确认；尚未发布。

**What to build:** 在没有本机严格核对窗口时，使用有效的当前合约与现货观察完成固定阈值库存决策和下一次操作准备，不再为此证明过去全部合约收入或生成历史保证金指标；操作开始后仍严格核对该窗口所需的结算证据。

**Context:** 当前历史保证金证明、库存状态持久化和执行资格共享完整收入审计前提。本票真正切断这条无关依赖，同时保留 USDⓈ-M 资产级额度、一致性检查和新操作后的严格结算。本票依赖固定阈值完成，避免取消历史指标后仍留下依赖其语义的预测决策。

**Scope:** 从当前账户读取、基线切换、库存周期推进、预算检查到执行前准备形成一条完整路径；诊断性历史与本机结算证据使用不同资格，不增设后台指标服务。

**Acceptance criteria:**

- [ ] 空闲阶段，缺少 6h/24h 快照、保证金历史基线、完整旧收入或旧区间资本流水分类，不再阻止库存状态、候选计数、成功库存时间和合规新动作。
- [ ] 在无需本机结算或其他明确业务证据的空闲路径中，即使合约收入接口被测试替身设为不可调用，也能完成有效库存周期和下一操作的提交前准备；不得通过输出零指标假装历史证明成功。
- [ ] 当前账户模式、币种支持、总额与资产行、钱包/版本以及资产级 maxWithdrawAmount 的现有校验保留；不扩大到多资产模式或新保证金币种。
- [ ] 合约与现货接受新基线时记录同一可追踪的证据边界；下一本机操作从最终有效账户开始严格核对，不再回放到已接受外部变化之前的旧历史基线。
- [ ] 旧快照和原始回执保留；明确区分库存观察记录、本地回执游标和可用于本机结算的证据。不能把本地游标、请求时间或资产 updateTime 当成已覆盖特定操作的因果证明。
- [ ] 在严格窗口内，缺失必须的成交明细、实际费用、划转身份、收入或任一侧余额覆盖，仍保持阻断。补齐后恢复同一操作，不补发、不重置预算与保护累计。
- [ ] 对跨基线边界迟到的回执，不能仅按回执时间判定其已经反映在新余额。归属无法证明时保留原始记录并阻断相关严格窗口，不丢弃、重复重放或吸收为外部输入。
- [ ] 所有库存推进和直接执行入口使用新的观察/窗口资格；不得通过遗留的收入审计标志重新引入空闲期全面审计，也不能产生只检查余额的直接执行旁路。
- [ ] 保留账户级滚动 24h 调出预算：人工及其他策略相关划转、PENDING、未决本机预占、身份去重和超过 24h 仍未决的预占均按原规则计算；回扫不返还预算。
- [ ] 预算所需的划转读取仍必需，读取失败不能按零预算使用额放行；maxWithdrawAmount、最小粒度硬 veto、单次比例、划出前后绝对下限及最终复核全部保持。
- [ ] 最新观察或预算使候选金额/需求改变时，结束旧候选，不在同轮自动改量重试；后续正常规划仍可生成新候选。行情/过滤器原始有效期、保护动作失效令牌和有界重读保持。
- [ ] 资金到账续作仍按已核验外部资金占用的现有规则结束。新基线接受事件不能作为外部占用证据；不能沿用已经跨越证据边界的旧“余额已覆盖”结论。证据不足时保留续作并诊断，不自动追加调资。
- [ ] 调资已结算、外部余额被新基线接受后，再导入该调资之后的迟到外部成交：仅凭回执落库或本地游标在当前游标以内，不能认定支出已被余额覆盖并结束旧续作。必须另有跨基线仍有效的覆盖证明；没有则保留续作、不追加调资。当前冻结订单仍可按原规则独立验证，不因基线变化一律禁用。
- [ ] 新 ADR 明确取代原“任何新库存/执行批次都需完整收入审计”的部分要求，保留严格窗口内的要求与账户新鲜度保障；同步设计和词汇，保留现有外部资金占用 ADR 的业务条件。
- [ ] 离线端到端验证空闲外部合约盈亏/入金、缺失旧历史、相关外部活动订单、三种本机划转方向、严格窗口内迟到收入，以及保护动作导致的资格失效。

**Verification:** 使用同一笔外部余额变化，分别放在本机窗口外与窗口内；前者按当前有效库存完成新周期，后者保持严格核对直到证据补齐。对最终额度、预算或订单变化注入竞态，确认无旧候选写出。

**Out of scope:** 接受最终一致余额代替本机结算证明、修改未知划转恢复、仅机器人预算、新买入金额预算、以纯余额不足结束资金续作。
