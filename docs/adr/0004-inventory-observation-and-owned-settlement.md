# 以当前库存决策，在本机责任窗口内严格结算

2026-10-16 用户确认六张本地 tickets，并授权依赖顺序实施。

固定库存阈值取代消耗预测。没有本机结算责任的空闲账户，可以接受有效的当前双账户库存，不再证明外部资金来源或旧 24h 收入；接受时保存共同回放边界与代次。所有开放本机 GTC、UNKNOWN、撤单和未结算终态仍保持严格窗口，使用原身份、实际成交费用、双向划转及余额/收入证明。

本决定取代 ADR 0003 中“每个新的库存或执行批次均需历史整段审计”的普遍要求。所需严格窗口仍完整复查，有限缓存、慢扫描后有界重读、原始账户/行情寿命和批次失效机制继续有效。执行资格独立于历史指标，不伪造零指标。

代价是放弃空闲期间完整来源解释，信任有效交易所观察；开放 GTC 期间的外部活动仍可能阻断。接受边界和本地游标不能证明单笔操作覆盖。保留账户级预算、所有划转硬限制和未知状态恢复。ADR 0002 的已核验外部占用退出条件不变；跨新边界的旧游标不再提供支出覆盖证明，当前冻结仍可独立验证。

实施规范见 DESIGN 6、7、9.2、11.2；不增加后台指标服务，不扩大账户模式或币种。

后续变更（2026-10-16）：资金续作退出条件已由 [ADR 0005](0005-current-funds-end-funded-continuation.md) 取代，改为当前资金不足；本记录保留原决定，下一库存周期屏障、预算、冷却与本机结算要求继续有效。
