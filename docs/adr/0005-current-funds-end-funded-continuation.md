# 当前资金不足结束已结算续作，下一库存周期重新评估

2026-10-16（Asia/Taipei）用户明确确认。

本机调资有可靠身份、已确认结算、相关操作没有未决责任，其他交易条件满足时，以当前可用稳定币判断能否形成最小合规买单。实际资金仍能缩量买入则继续；只有同一规划器在不受资金限制时能形成订单、实际资金却不能时，才结束旧续作。价格、精度、名义金额、费用、敞口、订单槽位、切片、追价、运行模式、数据新鲜度和急跌约束全部保留。

退出原子保存当前资金不足观察与下一库存周期屏障，使用 `FUNDING_INSUFFICIENT_FUNDS`，不声明资金来自哪笔支出或被冻结在哪里。本机 UNKNOWN、缺身份或未结算不能用当前余额替代。新 baseline 自身既不退出续作，也不追加调资。

普通行情或维护 tick、重启、预算随时间释放、同时间库存重放均不得追加调资。只有下一有效库存周期，在持久化冷却允许后重新通过账户级滚动预算、maxWithdrawAmount、最小粒度硬 veto、比例、绝对下限及最终提交复核，才可能发起一笔新调资。

本决定取代 ADR 0002 与 ADR 0004 的“须证明外部占用才能退出”部分；保留它们的同轮不补资、下一周期屏障及幂等恢复要求。空闲无需再为该退出条件查询外部支出成交或其他交易对冻结归属。严格窗口的证据和 BNB 相关订单检查保持。
