# 外部资金占用结束旧续作，新库存周期重新取得调资资格

共享现货资金可能在到账后被外部交易耗用或冻结，使尚未开始的资金到账续作长期无法执行。对账确认外部占用导致可用资金不足最小合规买单后，结束旧续作，仅在下一个有效库存周期重新评估是否调资；同次续作和同一调度轮仍禁止追加资金，所有划转风险和滚动预算保持有效。

这一边界避免永久等待不存在的可用资金，也避免行情 tick 在共享支出后连续补资。若尚能缩量买入则继续按已确认余额执行；单纯涨价、切片等待、临时行情限制、PAUSED、UNKNOWN 或余额未结算都不能充当外部资金占用证据。退出与下一库存周期资格必须跨重启保持。
